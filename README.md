# 🎬 CineMatch – Movie Recommendation System

**Discover movies that match your mood and interests!**

CineMatch is a responsive, web-based movie recommendation application developed using HTML, CSS, and JavaScript. It allows users to explore movies, search by title, filter by genre and rating, view movie details, and manage their favourite movies.

## 🌟 Project Overview

Finding a movie to watch can sometimes be difficult. CineMatch makes movie discovery easier by providing a simple and interactive platform where users can browse movies based on their preferences.

The application features a modern cinematic interface with a dark theme and a user-friendly design.

## ✨ Features

- 🎥 **Movie Collection:** Browse a collection of movies with posters and ratings.
- 🔍 **Search Functionality:** Search movies by title.
- 🎭 **Genre Filtering:** Filter movies by Action, Comedy, Romance, Thriller, Sci-Fi, and Drama.
- ⭐ **Rating Filter:** Find movies based on minimum ratings.
- ❤️ **Favourite Movies:** Add or remove movies from your favourites.
- 💾 **Local Storage:** Save favourite movies in the browser using localStorage.
- 📖 **Movie Details:** View movie descriptions, genres, posters, and ratings.
- 📱 **Responsive Design:** Designed to adapt to different screen sizes.
- 🎨 **Modern UI:** Dark cinematic theme with interactive styling.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/harinisherley24-create/movie-recommendation-system.git
```

### 2. Navigate to the project folder

```bash
cd movie-recommendation-system
```

### 3. Run the application

Open `index.html` in your web browser.

You can also use the Live Server extension in Visual Studio Code.
